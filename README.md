# Ad Studio — AIで作る30秒プロダクト広告動画（Remotion）

商品情報を入力するだけで、**キャラクターの掛け合い＋集中線・吹き出し・図解アニメ＋ナレーション＋BGM/効果音**の
SNS向け広告動画（縦型9:16 / 正方形1:1 / 横型16:9）を作れるツールです。

- **AI台本生成**（OpenAI）: ブリーフから「フック → 疑問 → 課題 → 解決 → 特徴×3 → 画面紹介 → CTA」の王道構成を自動作成
- **AIナレーション**: **ElevenLabs（Eleven v3）** で読み上げ。セリフの前に付く**オーディオタグ**（`[excited]` ワクワク・`[surprised]` 驚き・`[sighs]` ため息 など）で、セリフごとに気持ち・話し方・声の演技を乗せる。キャラの声は ElevenLabs の日本語の声から選ぶ・声のイメージから作る・手持ちの音声から作るのどれでも決められる
- **実写・イラストのキャラクター画像**: 人間は **速水さき**、人外は **おすしちゃん** を標準搭載。全表情に「口を閉じた画像／口を開けた画像」があり、**ナレーションの音声に合わせて口パク**、セリフごとに**表情が切り替わる**
- **オリジナルキャラも生成可能**（gpt-image）: デザインシートや説明文から、透過背景で全表情×口の開閉を作る
- **ブラウザエディター**: プレビューを見ながら文字・配色・キャラ配置を直し、そのままMP4に書き出し
- **ビート同期**: シーンの切り替えを BGM の8分音符に自動で合わせる
- **画面紹介は実際のUIのみ**: アプリ・管理画面などの**実スクリーンショット**を入れて見せる（疑似の画面は作りません）。縦に長い画像は自動でスクロール
- **AIなしでも使える**: 標準キャラ・組み込みBGM/効果音・テンプレート構成だけで動画を作れます

サンプルとして **SUSHI TOP OCR（レシート販促ソリューション）のCM（約40秒）** が入っています。

---

## セットアップ

必要なもの: **Node.js 20 以上**（22 推奨）。ffmpeg や Chrome は Remotion が自動で用意します。

```bash
npm install
cp .env.example .env   # OPENAI_API_KEY=sk-...（AI機能）と ELEVENLABS_API_KEY=...（ナレーション）を記入
npm run dev            # エディター http://localhost:5173 ／ API http://localhost:3210
```

初回起動時にサンプルプロジェクトが `projects/` にコピーされます。

> `.env` と `projects/`（作成した動画データ）は Git 管理外です。API キーをリポジトリにコミットしないでください。

## 使い方

### 1. 作る
- **AIで作る**（「新規作成」→「AIで作る」）: 3つのステップで台本まで作ります（30〜60秒）
  1. **素材**: 商品のWebページのURLや、資料（PDF・PowerPoint・Word・Excel・画像）をドロップ。無ければ「自分で入力する」
  2. **内容**: 商品名・ひとこと・ターゲット・課題・特徴・根拠を確認（資料から読み込んだ時は自動で入ります）
  3. **仕上がり**: 画面の向き・長さ・実際の画面のスクリーンショット・締めくくり・トーン →「台本を作る」
  - 右上の「記入例を使う」で SUSHI TOP OCR のブリーフが入ります
  - AI は書かれていない数字・実績を作らないよう指示してあります
- **テンプレートから作る**（「新規作成」→「テンプレートから作る」）: AIを使わず定番の構成のひな形から手で編集

### 2. 直す（エディター）
| 場所 | できること |
|---|---|
| 上のツールバー | ‹ でプロジェクト一覧へ・タイトルの変更・縦／正方形／横の切り替え・取り消し／やり直し・「AIで直す」（直し方を文章で伝える）・「書き出す」 |
| 左: シーン | 各シーンのサムネイル。クリックで移動、ドラッグで並べ替え、「…」で複製・移動・削除、下の「シーンを追加」 |
| 中央: 映像 | プレビュー。**一時停止中は、映像の要素をそのままつかんで動かせます**（下記「映像の上で直接編集」） |
| 下: タイムライン | 再生・シーク。シークバーがそのままシーンの並びになっていて、**シーンの右端をドラッグすると長さを伸び縮み**できます（ダブルクリックで自動に戻す） |
| セリフ | 再生位置のシーンのセリフを**いつも表示**。再生中は話しているセリフが強調され、「○秒〜」を押すとそのセリフの位置へ移動。表示の種類・表情・声の調子（オーディオタグ）・読み方・吹き出しのしっぽ・セリフのあとの間は最初から開いています |
| 右: シーン | このシーンの長さ（−／＋・自動に戻す）・文字・キャラクター・図解・小道具・演出 |
| 右: レイヤー | このシーンの要素（キャラ・吹き出し・見出し・図解など）の一覧。上ほど手前で、**ドラッグで重なり順**、目のアイコンで表示・非表示。選ぶと映像の上でも選ばれ、**位置（X・Y）・大きさ・回転を数値で**変えられます（最前面・最背面へのボタンも） |
| 右: デザイン | ブランド名・タグライン・ロゴ・カラー（プリセット／細かく調整）・フォント |
| 右: キャスト | キャラクターの見た目・声（「声を選ぶ…」で ElevenLabs のライブラリ／自分の声／声を作る／手持ちの音声から決める）・話す速さ・表情の画像・AIでオリジナルの見た目を作る |
| 右: サウンド | ナレーション（音声エンジンの状態・セリフの音声の確認と作り直し）・BGM・効果音・字幕 |

- テキストの `[[ ]]` で囲んだ部分はブランドカラーで強調されます（例: `[[レシート]]を撮るだけで`）。改行は入力欄でそのまま改行。
- **シーンとシークバーは連動**します。再生・シーク・シーン一覧のクリックのどれでも、シーン一覧の選択・セリフ・右の設定が再生位置のシーンに切り替わります。
- **シーンの長さ**: ふだんは自動（セリフの長さと文字を読む時間から計算）。タイムラインの右端をドラッグするか、右の「長さ」の −／＋ で伸び縮みでき、「自動に戻す」で元に戻ります。カットは BGM の拍に合わせるので1拍（150BPMなら0.2秒）刻みで、**セリフの途中では切れません**（最後のセリフを言い終わるまでより短くはなりません）。
- 設定の開閉（「演出」など）は最初から開いていて、閉じた状態は次回も覚えています。
- 「読み方」にカタカナ/ひらがなを入れると TTS の読み間違いを直せます（例: `SUSHI TOP OCR` → `スシトップ オーシーアール`）。
- セリフを変えると、そのセリフだけ音声が古くなります。映像の上に「音声がまだないセリフが N 件あります」と出るので、「音声を作成」で変更分だけ作り直します。
- ⌘Z / ⇧⌘Z（Windows は Ctrl+Z / Ctrl+Shift+Z）で取り消し／やり直し、スペースで再生／停止、何も選んでいない時は ← → でコマ送り（Shift で1秒）。
- 画面の明るさは OS のライト／ダークの設定に合わせます。

### 3. 書き出す
「書き出す」→ H.264 + AAC の MP4（1080×1920 など）。30秒で2〜4分程度。
ファイルは `projects/<id>/renders/` に保存され、ダイアログからダウンロードできます。

## 動画の組み立て（シーンの種類）

| type | 見た目 | 主な設定 |
|---|---|---|
| `logo` | 回転する集中線、ギザギザの爆発にロゴが叩きつけられる、ブランド名の帯が流れる | ロゴ文字（改行可）、サブコピー（タイプライター表示） |
| `talk` | ストライプ背景でキャラが吹き出しで会話。？？や汗などの記号、NG/OKバッジ付きの小道具が落ちてくる | 見出し、記号、小道具 |
| `feature` | 1行目＋特大見出しが衝撃リングと画面揺れで登場し、下に図解 | 図解: A→B / アイコン並び / 積み上げ→完了 / 障壁ジャンプ / 数字カウント / Before→After / 画像 |
| `showcase` | 実際の画面のスクリーンショットを、スマホ枠（縦長）またはブラウザ枠（横長）で見せる。枠より縦に長い画像はゆっくりスクロール。**画像が未設定だと書き出せません** | タイトル、注記、スクリーンショット |
| `cta` | ロゴ・光が走るボタン・連絡先・注記、キラキラ | ボタン文言、連絡先、注記 |

シーンの長さはセリフ音声の長さから自動計算され（エディターで手動で伸び縮みも可能）、BGM のビートに吸着します。見出しは「同じ文言を読むセリフ」のタイミングに合わせて出ます。
効果音（ポップ・ワイプ・インパクト・コイン・ディン等）は演出に合わせて自動配置され、セリフ中は BGM が自動で下がります（ダッキング）。

## キャラクター

- **速水さき**（人間・`hayami-saki`）／**おすしちゃん**（人外・`osushi-chan`）を標準搭載。1人目が主人公（説明役）、2人目が相方（リアクション役）です。
- 画像は `public/characters/<id>/` にあり、表情ごと（通常/喜び/驚き/しょんぼり/考え中/指さし/手を振る/ウインク）に
  `<表情>.webp`（口を閉じた画像）と `<表情>-open.webp`（口を開けた画像）があります。**口以外は画素単位で完全に同一**なので、口パクしても全身がちらつきません。
  - おすしちゃんは通常は口が無いデザインのため、口パクの時だけ小さな口が現れます。
  - `reference.webp` が元のデザインシートです。
- **口パク**: ナレーション生成時に音量から口の開閉（30Hz）を計算して保存し、再生時に2枚の画像を切り替えます。セリフごとの `pose`（表情）で顔が切り替わります。
- **オリジナルキャラ**: 「キャスト」タブの「AIでオリジナルの見た目を作る」で、基準にする画像（任意）と説明文から全表情×口の開閉を生成します（8表情で約10分）。
  1) 通常の表情 → 2) 他の表情（通常を参照して同じ見た目に） → 3) 各表情の口開け版（AIが口だけを開けた画像を作り、差分から口の位置を自動検出して**口のまわりだけ**を閉じ口画像に合成） → 4) 余白を全画像で共通に詰める。
- 標準キャラの作り直し: `npx tsx scripts/build-character.ts hayami-saki`（`--only=happy,sad` で一部だけ）

## ナレーション（ElevenLabs）

ナレーションは **[ElevenLabs](https://elevenlabs.io)** の **Eleven v3**（`eleven_v3`）で作ります。日本語に対応し、**オーディオタグ**で感情を乗せられます。

```bash
# .env に API キーを書いて、サーバーを再起動
ELEVENLABS_API_KEY=sk_...
```

- API キーは ElevenLabs の「Developers → API Keys」で作ります。権限を絞る場合は **Text to Speech・Voices（読み書き）・User（読み取り）** を許可してください。
- エディターの「サウンド」タブで、接続状態と今月の残り文字数（クレジット）を確認できます。
- **声の調子（オーディオタグ）**: セリフ欄の「声の調子」でタグを選ぶと、セリフの前に `[excited]` のように付いて、その気持ちで読まれます。
  - 気持ち（ワクワク・驚き・自信たっぷり・ほっと・心配・困惑 など）／話し方（元気よく・落ち着いて・ささやき・早口 など）／声の演技（笑う・ため息・息をのむ など）から最大3つ。英語で自由に書くこともできます（例: `laughs softly`）。
  - 選んでいない時は、「演技指示」の言葉（「驚いて」→驚き、「しょんぼり」→悲しい、「自信たっぷりに」→自信たっぷり など）から自動で付きます。「タグなし」も選べます。
  - 「読み方」の文の途中にも `えっ、[laughs] ほんとに？` のように書けます。
  - AI台本は、セリフごとに合うタグを自動で選びます。
- **キャラの声**: 「キャスト」タブの「声を選ぶ…」で決めます。
  - **ライブラリ**: ElevenLabs の共有ライブラリの日本語の声を試聴して選ぶ（選ぶと自分の声に追加されます）
  - **自分の声**: ElevenLabs のアカウントにある声から選ぶ
  - **声を作る**: 声のイメージ（日本語でOK）から候補を作り、聴き比べて保存（Voice Design）
  - **手持ちの音声**: 音声ファイルから声を作る（Instant Voice Cloning。Starter 以上のプラン。**自分の声、または許諾を得た声のみ**）
- **標準の声**: 速水さき・おすしちゃんは、声を選んでいなければ同梱の音声（`public/voices/hayami-saki.wav` / `osushi-chan.wav`）を初回の音声作成時に ElevenLabs へ登録（クローン）して、その声で読みます。クローンできないプランでは、キャラの「声のイメージ」から声を作ります。登録した声は `voices/elevenlabs.json` に覚えておき、2回目からは使い回します（ElevenLabs 側で消すと、次回に作り直します）。
- **話す速さ**: キャラごとに ×0.8〜1.3（既定 ×1.10）。×1.2 までは ElevenLabs が、それを超える分は生成後に音程を変えずに縮めます。
- **シーンが変わっても声をそろえる**: 「音声を作成」では、台本全体を1回で読み上げ（Text to Dialogue）、セリフごとに切り分けて保存します。セリフを1つずつ別々に作ると、短い文ほど声が揺れて、シーンによって別の人のように聞こえるためです。そのため、セリフを1つでも変えると全体を読み直します（30秒の広告で150文字前後）。セリフ一覧の「作り直す」は、そのセリフだけを前後の文を手がかりに作ります。プランやモデルの都合でまとめて読めない時は、自動で1セリフずつに切り替えます。
- **表現の幅**（サウンドタブ・全セリフ共通）: 安定・自然・豊か。豊かなほどタグの気持ちが強く出ますが、まれに読み方が崩れます。
- 生成した音声はセリフごとに保存され、文・タグ・声・速さ・表現の幅が変わると作り直しの対象になります（ElevenLabs のクレジットは作った分だけ使います）。
- 設定: `ELEVENLABS_MODEL`（既定 `eleven_v3`。お使いのアカウントで使えるなら `eleven_v4` も可）、`ELEVENLABS_LANGUAGE`（既定 `ja`）、`ELEVENLABS_CONCURRENCY`（同時に作る数。既定3）、`ELEVENLABS_BASE_URL`（EU などのデータ所在地を使う時）。

### Irodori-TTS / OpenAI TTS を使う場合

`.env` で `TTS_PROVIDER=irodori`（または `openai`）にすると、以前のエンジンに切り替えられます。CLI は `npm run make -- brief.json --tts=irodori` のように1回だけ切り替えることもできます。

```bash
npm run irodori                      # Irodori-TTS サーバーを起動（初回はダウンロード＋インストール。uv と git が必要）
IRODORI_TTS_URL=http://127.0.0.1:8088  # .env に接続先を書く
```

- Irodori-TTS ではオーディオタグの代わりに、感情の絵文字と演技指示で調子を付けます（タグは読み上げません）。速水さき・おすしちゃんは、参照音声を選んでいなくても標準の声で読みます（以前の版で声を固定せずに作った音声は、セリフごとに声が違うので作り直しの対象になります）。声は「声を選ぶ…」で候補を作って参照音声として固定します（参照音声は `voices/` に保存）。
- CPU では1セリフ30〜60秒かかります（`IRODORI_NUM_STEPS=20` などで速くなりますが、品質は下がります）。生成音声に不可視の透かし（SilentCipher）が入る場合があります。

- **社内向けに Web 公開**: Google アカウント（会社のドメイン限定）でログインした人だけが使えるようにできます。この PC から Cloudflare Tunnel で公開する方法と、Docker でクラウドに置く方法は [docs/deploy.md](docs/deploy.md)。
- **URL・資料から作る**: 「AIで新しく作る」の一番上で、商品のWebページのURLや、サービス資料（PDF・PowerPoint・Word・Excel・テキスト・画像）を読み込むと、AIが商品名・ターゲット・課題・特徴・実績・CTA・注記・ブランドカラーを下書きして入力欄を埋めます（資料に無い数字は作りません。読み取れなかった点は「確認してほしい点」に出ます）。CLI は `npm run make -- --url=https://… --doc=資料.pdf --hint="〇〇について"`（作ったブリーフは briefs/ に保存）。
- **製品のUI画面（`SUSHI UI/`）**: フォルダに入れたスクリーンショットを画像認識AIが一度だけ解析し（何の画面か・スマホかPCか・見どころの範囲・画質。結果は `SUSHI UI/.ui-index.json` にキャッシュ）、台本AIが特徴シーンや画面紹介に合う画面を選びます。PC画面は見どころを中心に切り抜いて大きく映します。フォルダは `.env` の `UI_LIBRARY_DIR` で変更でき、CLI では `--no-ui-library` で使わないようにできます。小さな画像（幅360px未満のスマホ画面など）はぼやけるので、元の解像度の画像を入れるほど仕上がりが良くなります。
- **特徴シーンの素材**: アイコンと矢印の図解は使わず、「実際の製品画面」→ 合う画面が無ければ「画像AIのイラスト（解決した後の場面）」→ 根拠のある数字だけ「カウンター」の順で選びます。イラストはシーン欄の図解で指示文を直して「AIで描き直す」ことができます。
- **課題の図解**: 台本を作ると、課題シーンの図解イラスト（文字なし）を画像AI（既定 `gpt-image-2.5-sunburst`、`OPENAI_ILLUSTRATION_MODEL` で変更可）で自動生成し、NGスタンプとラベルを重ねて大きく表示します。シーン欄の「小道具 → 図解イラスト」で作り直し・画像の差し替え・外すができます。CLI では `--no-illustration` で省略できます。
- **画面の形ごとの配置**: 映像の上で調整した位置・大きさ・回転・重なり順・吹き出しのしっぽは、縦型・正方形・横型で別々に保存されます（縦型で動かしても横型には影響しません）。
- **映像の上で直接編集**: 一時停止中は、映像の要素（キャラ・吹き出し・字幕・見出し・ロゴ・ボタン・小道具・図解・画面・演出など）をそのまま編集できます（モードの切り替えは不要）。マウスを乗せると枠が出て、クリックで選択 → ドラッグで移動、右下の角で拡大縮小、上の丸で回転（Shiftで15度刻み）。選ぶと出る小さなバーで、縮小・拡大・元に戻す・文字揃え・隠す（Delete キーも可）ができ、矢印キーで1px（Shiftで10px）動かせます。文字は**ダブルクリック**で書き換え、⌘Enter（Ctrl+Enter）か枠外クリックで確定します。要素を選んでいる間は、そのシーンの全要素（時間で出入りする吹き出し・字幕・小道具なども）が出た状態で止まり、Esc で選択を外すと再生位置のコマに戻ります。重なって選びにくい要素の選択、隠した要素の復元、重なり順の変更、調整のリセットは「レイヤー」タブで行えます（映像の上で触っても重なり順は変わりません）。調整はシーンごとに保存され、書き出しにもそのまま反映されます（取り消し: ⌘Z）。背景は対象外です。文字を書き換えたセリフは、読み方の別表記を外して音声の作り直し対象になります。
- **声の権利**: 実在の人物の声を無断で再現する用途には使わないでください。ElevenLabs の利用規約・プランの商用利用条件も確認してください。

## OpenAI の使い方

| 用途 | 既定モデル | 環境変数 |
|---|---|---|
| 台本生成・AI修正（Structured Outputs） | `gpt-5.5` | `OPENAI_TEXT_MODEL` |
| ナレーション（OpenAI TTS を選んだ場合。`instructions` にキャラの声＋セリフごとの演技指示） | `gpt-4o-mini-tts` | `OPENAI_TTS_MODEL` |
| キャラ画像（透過背景・表情差分・口開け差分） | `gpt-image-2` | `OPENAI_IMAGE_MODEL` |

API キーはサーバー側（`.env`）だけで使われ、ブラウザには送られません。コストは画像生成が最も大きく、台本とナレーションは軽量です。

## トラブルシューティング

- **書き出しで Chrome のダウンロードに失敗する**: 社内プロキシ等で失敗する場合は、手元の Chrome/Chromium のパスを `.env` の `REMOTION_BROWSER_EXECUTABLE` に設定してください。
- **「ElevenLabs の API キーが未設定です」**: `.env` に `ELEVENLABS_API_KEY` を書いて、サーバーを再起動してください。キーの権限を絞っている時は Text to Speech・Voices を許可します。
- **ElevenLabs の文字数を使い切った**: 「サウンド」タブで今月の残りを確認できます。変更したセリフだけ作り直されるので、何度も全体を作り直す必要はありません。
- **気持ちが乗らない／大げさすぎる**: 「声の調子」のタグを変えるか、キャストの「表現の幅」を調整します（豊か＝強く出る、安定＝控えめ）。タグは1〜2つが目安です。
- **Irodori-TTS を使う時に接続できない**: `npm run irodori` を起動したままにしてください。ポートやURLを変えた場合は `.env` の `IRODORI_TTS_URL` も合わせます。
- **AIボタンが押せない**: `.env` の `OPENAI_API_KEY` を設定してサーバーを再起動してください。
- **読み方がおかしい**: セリフの「読み方」欄に、読み間違える語だけをカタカナにして入れる（句読点は残す。全文をひらがなにしたりスペースで区切ると不自然になります）。
- **棒読みに聞こえる**: セリフの「声の調子」でタグを選ぶか、「演技指示」に気持ちを書く（例: 驚いて／困って小声で → 自動でタグになります）。
- **文字がはみ出す**: 見出しは6文字前後、吹き出しは1行12文字以内が目安です。改行で調整できます。
