# Ad Studio — AIで作る30秒プロダクト広告動画（Remotion）

商品情報を入力するだけで、**キャラクターの掛け合い＋集中線・吹き出し・図解アニメ＋ナレーション＋BGM/効果音**の
SNS向け広告動画（縦型9:16 / 正方形1:1 / 横型16:9）を作れるツールです。

- **AI台本生成**（OpenAI）: ブリーフから「フック → 疑問 → 課題 → 解決 → 特徴×3 → 画面紹介 → CTA」の王道構成を自動作成
- **AIナレーション**: 日本語に強い **Irodori-TTS**（ローカル実行）または OpenAI TTS を切り替え可能。キャラごとに声・話し方を設定し、**セリフごとの演技指示・感情の絵文字**（「驚いて」😲「しょんぼりして」🥺）で抑揚を付ける。無理な速度変更はせず自然な速さで読み上げる
- **実写・イラストのキャラクター画像**: 人間は **速水さき**、人外は **おすしちゃん** を標準搭載。全表情に「口を閉じた画像／口を開けた画像」があり、**ナレーションの音声に合わせて口パク**、セリフごとに**表情が切り替わる**
- **オリジナルキャラも生成可能**（gpt-image）: デザインシートや説明文から、透過背景で全表情×口の開閉を作る
- **ブラウザエディター**: プレビューを見ながら文字・配色・キャラ配置を直し、そのままMP4に書き出し
- **ビート同期**: シーンの切り替えを BGM の8分音符に自動で合わせる
- **画面紹介は実際のUIのみ**: アプリ・管理画面などの**実スクリーンショット**を入れて見せる（疑似の画面は作りません）。縦に長い画像は自動でスクロール
- **AIなしでも使える**: 標準キャラ・組み込みBGM/効果音・テンプレート構成だけで動画を作れます

サンプルとして **SUSHI TOP OCR（レシート販促ソリューション）のCM（約40秒）** が入っています。

---

## セットアップ

必要なもの: **Node.js 20 以上**（22 推奨）。ffmpeg や Chrome は Remotion が自動で用意します。

```bash
npm install
cp .env.example .env   # OPENAI_API_KEY=sk-... を記入（AI機能を使う場合）
npm run dev            # エディター http://localhost:5173 ／ API http://localhost:3210
```

初回起動時にサンプルプロジェクトが `projects/` にコピーされます。

> `.env` と `projects/`（作成した動画データ）は Git 管理外です。API キーをリポジトリにコミットしないでください。

## 使い方

### 1. 作る
- **✨ AIで新しく作る**: 商品名・ひとこと説明・ターゲット・課題・特徴・CTA を入力 →「台本を生成」（30〜60秒）
  - 「記入例を入れる」で SUSHI TOP OCR のブリーフが入ります
  - AI は書かれていない数字・実績を作らないよう指示してあります
- **テンプレートから作る**: AIを使わず王道構成の雛形から手で編集

### 2. 直す（エディター）
| 場所 | できること |
|---|---|
| 左: シーン一覧 | 並べ替え・複製・削除・追加（ロゴ / 会話 / 特徴 / 画面紹介 / エンドカード） |
| 中央: プレビュー | Remotion Player で即時プレビュー。下のタイムラインでシーンへジャンプ |
| 右: シーン | 見出し・セリフ・吹き出しの種類・表情・キャラ配置・図解・トランジション・背景 |
| 右: ブランド | ブランド名・タグライン・ロゴ画像・配色（プリセットあり）・フォント |
| 右: キャラ・声 | 標準キャラ／画像キャラ、表情ごとの画像、AI画像生成、声（Irodori: キャプション・シード・参照音声 / OpenAI: ボイス・話し方）・速さ・試聴 |
| 右: 音・設定 | BGM（組み込み/なし/アップロード）・BPM・効果音・ナレーション（音声エンジン切替）・字幕 |
| 上部 | 9:16 / 1:1 / 16:9 切替、✨AIで修正（自然文で改稿指示）、🎙ナレーション生成、⬇書き出し |

- テキストの `[[ ]]` で囲んだ部分はブランドカラーで強調されます（例: `[[レシート]]を撮るだけで`）。改行は入力欄でそのまま改行。
- 「読み方」欄にカタカナ/ひらがなを入れると TTS の読み間違いを直せます（例: `SUSHI TOP OCR` → `スシトップ オーシーアール`）。
- セリフを変えると、そのセリフだけ「音声なし」になります。「ナレーション生成」で変更分だけ作り直します。
- Ctrl+Z / Ctrl+Shift+Z で元に戻す／やり直し、スペースで再生／停止。

### 3. 書き出す
「⬇ 書き出し」→ H.264 + AAC の MP4（1080×1920 など）。30秒で2〜4分程度。
ファイルは `projects/<id>/renders/` に保存され、ダイアログからダウンロードできます。

## コマンドライン

```bash
# ブリーフJSON → AI台本 → ナレーション → MP4 を一気に
npm run make -- briefs/sushitop-ocr.json
npm run make -- briefs/sushitop-ocr.json --format=horizontal --character="オレンジのパーカーの女の子"

# 既存プロジェクトを書き出し（形式だけ変えることも可）

npm test            # ユニットテスト
npm run typecheck
npm run audio:build # 組み込みBGM・効果音を再合成
```

## 動画の組み立て（シーンの種類）

| type | 見た目 | 主な設定 |
|---|---|---|
| `logo` | 回転する集中線、ギザギザの爆発にロゴが叩きつけられる、ブランド名の帯が流れる | ロゴ文字（改行可）、サブコピー（タイプライター表示） |
| `talk` | ストライプ背景でキャラが吹き出しで会話。？？や汗などの記号、NG/OKバッジ付きの小道具が落ちてくる | 見出し、記号、小道具 |
| `feature` | 1行目＋特大見出しが衝撃リングと画面揺れで登場し、下に図解 | 図解: A→B / アイコン並び / 積み上げ→完了 / 障壁ジャンプ / 数字カウント / Before→After / 画像 |
| `showcase` | 実際の画面のスクリーンショットを、スマホ枠（縦長）またはブラウザ枠（横長）で見せる。枠より縦に長い画像はゆっくりスクロール。**画像が未設定だと書き出せません** | タイトル、注記、スクリーンショット |
| `cta` | ロゴ・光が走るボタン・連絡先・注記、キラキラ | ボタン文言、連絡先、注記 |

シーンの長さはセリフ音声の長さから自動計算され、BGM のビートに吸着します。見出しは「同じ文言を読むセリフ」のタイミングに合わせて出ます。
効果音（ポップ・ワイプ・インパクト・コイン・ディン等）は演出に合わせて自動配置され、セリフ中は BGM が自動で下がります（ダッキング）。

## キャラクター

- **速水さき**（人間・`hayami-saki`）／**おすしちゃん**（人外・`osushi-chan`）を標準搭載。1人目が主人公（説明役）、2人目が相方（リアクション役）です。
- 画像は `public/characters/<id>/` にあり、表情ごと（通常/喜び/驚き/しょんぼり/考え中/指さし/手を振る/ウインク）に
  `<表情>.webp`（口を閉じた画像）と `<表情>-open.webp`（口を開けた画像）があります。**口以外は画素単位で完全に同一**なので、口パクしても全身がちらつきません。
  - おすしちゃんは通常は口が無いデザインのため、口パクの時だけ小さな口が現れます。
  - `reference.webp` が元のデザインシートです。
- **口パク**: ナレーション生成時に音量から口の開閉（30Hz）を計算して保存し、再生時に2枚の画像を切り替えます。セリフごとの `pose`（表情）で顔が切り替わります。
- **オリジナルキャラ**: 「キャラ・声」タブで、基準にする画像（任意）と説明文から全表情×口の開閉を生成します（8表情で約10分）。
  1) 通常の表情 → 2) 他の表情（通常を参照して同じ見た目に） → 3) 各表情の口開け版（AIが口だけを開けた画像を作り、差分から口の位置を自動検出して**口のまわりだけ**を閉じ口画像に合成） → 4) 余白を全画像で共通に詰める。
- 標準キャラの作り直し: `npx tsx scripts/build-character.ts hayami-saki`（`--only=happy,sad` で一部だけ）

## ナレーションの音声エンジン（Irodori-TTS / OpenAI TTS）

日本語の自然さを重視するなら **[Irodori-TTS](https://github.com/Aratako/Irodori-TTS)**（MIT・日本語専用の音声合成）を使います。
このツールとは別プロセスのローカルサーバー（OpenAI互換API）として動かし、動画側からは HTTP で呼び出します。

```bash
# 1) Irodori-TTS サーバーをセットアップして起動（初回のみダウンロード＋インストール。uv と git が必要）
npm run irodori                      # NVIDIA GPU があれば自動で CUDA 版、なければ CPU 版
IRODORI_BACKEND=cpu npm run irodori  # 明示する場合（cu128 / rocm / cpu）

# 2) .env に接続先を書く（TTS_PROVIDER=auto なら、これだけで Irodori-TTS が既定になります）
IRODORI_TTS_URL=http://127.0.0.1:8088
```

- エディターの「音・設定」→「音声合成エンジン」でプロジェクトごとに切り替えられます（`自動 / Irodori-TTS / OpenAI TTS`）。接続状態も表示されます。CLI は `npm run make -- brief.json --tts=irodori`。
- **声の作り方**: 「キャラ・声」タブの ①**声のデザイン**（キャプション。年齢・声質・話し方を日本語で書く）＋②**声のシード**（同じ数字なら同じ声。気に入る声が出るまで試聴で数字を変える）。標準キャラ（速水さき／おすしちゃん）には設定済みです。
  声を完全に固定したい場合は**参照音声**を使います。「キャラ・声」タブの「🧪 参照音声をつくる」で、声のイメージと試し読み文から候補を作り（何度でもやり直せます）、聴き比べて気に入った1本を「この声に決定」すると、そのキャラの全セリフがその声で読まれます（決定後にナレーションを生成し直してください）。手持ちの音声ファイルを登録することもできます（**自分の声、または許諾を得た声のみ**。他人の声のまねは禁止です）。
  参照音声は Irodori サーバーの `voices/` と、このアプリの `voices/`（控え。`VOICES_DIR` で変更可）に保存されます。サーバー側から消えても、次の合成時に控えから自動で再登録されます。
- **社内向けに Web 公開**: Google アカウント（会社のドメイン限定）でログインした人だけが使えるようにできます。この PC から Cloudflare Tunnel で公開する方法と、Docker でクラウドに置く方法は [docs/deploy.md](docs/deploy.md)。
- **URL・資料から作る**: 「AIで新しく作る」の一番上で、商品のWebページのURLや、サービス資料（PDF・PowerPoint・Word・Excel・テキスト・画像）を読み込むと、AIが商品名・ターゲット・課題・特徴・実績・CTA・注記・ブランドカラーを下書きして入力欄を埋めます（資料に無い数字は作りません。読み取れなかった点は「確認してほしい点」に出ます）。CLI は `npm run make -- --url=https://… --doc=資料.pdf --hint="〇〇について"`（作ったブリーフは briefs/ に保存）。
- **製品のUI画面（`SUSHI UI/`）**: フォルダに入れたスクリーンショットを画像認識AIが一度だけ解析し（何の画面か・スマホかPCか・見どころの範囲・画質。結果は `SUSHI UI/.ui-index.json` にキャッシュ）、台本AIが特徴シーンや画面紹介に合う画面を選びます。PC画面は見どころを中心に切り抜いて大きく映します。フォルダは `.env` の `UI_LIBRARY_DIR` で変更でき、CLI では `--no-ui-library` で使わないようにできます。小さな画像（幅360px未満のスマホ画面など）はぼやけるので、元の解像度の画像を入れるほど仕上がりが良くなります。
- **特徴シーンの素材**: アイコンと矢印の図解は使わず、「実際の製品画面」→ 合う画面が無ければ「画像AIのイラスト（解決した後の場面）」→ 根拠のある数字だけ「カウンター」の順で選びます。イラストはシーン欄の図解で指示文を直して「AIで描き直す」ことができます。
- **課題の図解**: 台本を作ると、課題シーンの図解イラスト（文字なし）を画像AI（既定 `gpt-image-2.5-sunburst`、`OPENAI_ILLUSTRATION_MODEL` で変更可）で自動生成し、NGスタンプとラベルを重ねて大きく表示します。シーン欄の「小道具 → 図解イラスト」で作り直し・画像の差し替え・外すができます。CLI では `--no-illustration` で省略できます。
- **標準の声**: 速水さき・おすしちゃんは、同梱の音声（`public/voices/hayami-saki.wav` / `osushi-chan.wav`）を参照音声として、Irodori-TTS でその声で読み上げます（サーバーへの登録は自動）。
- **画面の形ごとの配置**: 直接調整の位置・大きさ・回転・重なり順・吹き出しのしっぽは、縦型・正方形・横型で別々に保存されます（縦型で動かしても横型には影響しません）。
- **直接調整**: 上部の「✎ 直接調整」をONにすると、プレビュー上の要素（キャラ・吹き出し・字幕・見出し・ロゴ・ボタン・小道具・図解・画面・演出など）を直接編集できます。クリックで選択 → ドラッグで移動、右下の ⤡ で拡大縮小、上の ⟳ で回転（Shiftで15度刻み）、「削除」で非表示（Delete キーも可）、矢印キーで1px（Shiftで10px）移動。文字は**ダブルクリック**（または「文字」）で書き換え、Ctrl+Enter か枠外クリックで確定します。直接調整中は、調整中のシーンの全要素（時間で出入りする吹き出し・字幕・小道具なども）が出た状態で止まります。文字を含む要素には、左揃え・中央揃え・右揃えのボタンが出ます。重なって選びにくい要素は、シーン欄の「🧩 要素の表示・調整」の名前をクリックすると選べます。非表示にした要素の復元や、調整のリセットは、シーン欄の「🧩 要素の表示・調整」から行えます。調整はシーンごとに保存され、書き出しにもそのまま反映されます（元に戻す: Ctrl+Z）。背景は対象外です。文字を書き換えたセリフは、読み方の別表記を外して音声の作り直し対象になります。
- **感情**: セリフごとに「感情」（絵文字）と「演技指示」を付けると調子が変わります（AI台本生成も自動で付けます）。効き方は文脈で変わるので、試聴して調整してください。
- **速度の目安**: GPU なら1セリフ数秒。**CPU では1セリフ30〜60秒**かかります（サンプルのCM 15セリフで約5〜10分）。`IRODORI_NUM_STEPS=20` などで速くなりますが、品質は下がります。
- 生成した音声はセリフごとに保存され、変更したセリフだけ作り直されます。エンジンや声の設定を変えると、対象の音声が作り直しになります。
- ライセンス・注意: Irodori-TTS は MIT ですが、生成音声に不可視の透かし（SilentCipher）が入る場合があります。実在の人物の声を無断で再現する用途には使わないでください。

## OpenAI の使い方

| 用途 | 既定モデル | 環境変数 |
|---|---|---|
| 台本生成・AI修正（Structured Outputs） | `gpt-5.5` | `OPENAI_TEXT_MODEL` |
| ナレーション（OpenAI TTS を選んだ場合。`instructions` にキャラの声＋セリフごとの演技指示） | `gpt-4o-mini-tts` | `OPENAI_TTS_MODEL` |
| キャラ画像（透過背景・表情差分・口開け差分） | `gpt-image-2` | `OPENAI_IMAGE_MODEL` |

API キーはサーバー側（`.env`）だけで使われ、ブラウザには送られません。コストは画像生成が最も大きく、台本とナレーションは軽量です。

## トラブルシューティング

- **書き出しで Chrome のダウンロードに失敗する**: 社内プロキシ等で失敗する場合は、手元の Chrome/Chromium のパスを `.env` の `REMOTION_BROWSER_EXECUTABLE` に設定してください。
- **Irodori-TTS に接続できない**: `npm run irodori` を起動したままにしてください（初回はモデル読み込みに数分）。ポートやURLを変えた場合は `.env` の `IRODORI_TTS_URL` も合わせます。
- **Irodori-TTS の声が毎回違う／気に入らない**: 「声のシード」を固定して、数字を変えながら試聴します。キャプションは具体的に（年齢・性別・声の高さ・話す速さ）。
- **AIボタンが押せない**: `.env` の `OPENAI_API_KEY` を設定してサーバーを再起動してください。
- **読み方がおかしい**: セリフの「読み方」欄に、読み間違える語だけをカタカナにして入れる（句読点は残す。全文をひらがなにしたりスペースで区切ると不自然になります）。
- **棒読みに聞こえる**: セリフの「感情」（絵文字）や「演技指示」に気持ちを書く（例: 驚いて／困って小声で）。キャラの「話し方の指示」も調整できます。話速の既定は ×1.30（テンポの速いCM調）です。台本の文字数もこの速さを前提に作られます。
- **文字がはみ出す**: 見出しは6文字前後、吹き出しは1行12文字以内が目安です。改行で調整できます。
